# 弹层关闭交互优化记录

日期：2026-10-29。用户要求筛选面板及同类页面支持点击外侧空白关闭。本阶段在已发行 0.21.1 之后本地开发，不代表该正式包已包含改动；本次未授权推送或发布。

## 行为约定

- 筛选与分类、曲目详情、标签整理、标签词典、普通编辑及额度弹窗统一支持外侧点击／触摸关闭；动态创建的弹窗自动适用。
- 关闭经过与 Escape 一致的取消事件，保留额度设置等已有的未保存确认和保存中拦截。不会触发保存或应用筛选；筛选草稿与原关闭按钮一致，再次打开读取已应用条件。
- 面板内部内容及内边距点击不关闭。按下和松开必须都在同一面板外侧，移动超过 8px、右键及触摸取消不触发关闭，防止拖拽／滚动误关。
- 关闭不会点击穿透到背景按钮；叠加弹窗只处理当前最上层。保留浏览器的 Escape 与焦点恢复行为。
- 完整 API Key 和临时密码仅展示一次，保留显式关闭，避免误点失去凭据。
