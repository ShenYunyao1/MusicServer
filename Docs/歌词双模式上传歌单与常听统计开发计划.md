# 歌词双模式、上传歌单与常听统计开发计划

2026-11-02。用户已同意功能方案，另提出手机系统最低音量仍过大的问题，本计划一并记录。按阶段本地开发、验证后提交；推送及正式发布另行明确授权。只关注schema 8及后续升级阶段。

## 一、歌词双模式

保留现有折叠状态的上一组／当前组／下一组与双语显示。标题增加展开／折叠按钮，展开后显示完整歌词，支持滚轮、鼠标按住上下拖动浏览和手机滑动。手动浏览暂停自动跟随，提供“回到当前歌词”；点击歌词组跳转并播放对应时间，拖动不能误触跳播。折叠立即回到当前组；切歌保留展开偏好，但新曲目恢复跟随。歌词与播放列表继续互斥。无时间轴只允许文本阅读。

主要文件：server/internal/music/online-player.js、online-player.css、lyrics-parser.js；测试为server/tests/online-player-contract.cjs、online-player-ui.cjs、playlist-playback-ui.cjs。

## 二、本次上传目标歌单

现有upload-batch.js已经支持目标选择、搜索分页、批量入库后归入歌单及仅重试歌单添加。本期优化明显入口，避免重复创建第二套逻辑。上传区顶部独立显示“本次上传到”：仅加入曲库／自己可编辑的一个歌单，支持搜索及快速新建并选中。各任务显示目标；任务开始后固定目标，之后选择只影响待开始项及新任务，恢复时保留任务原目标。目标失效允许另选；已入库但添加失败仅重试歌单操作，不能重复上传音频。既有曲目不重复添加。

主要文件：server/internal/music/upload-batch.js、upload-flow.js、upload-flow.css、upload-resume.js；沿用现有歌单与上传接口。测试覆盖upload-batch-contract.cjs及真实上传浏览器专项。

## 三、我常听的

音乐分组新增“我常听的”，仅当前账户可读；提供全部／近30天／近7天、名称搜索、20／30／50分页。按有效播放次数降序，同次数按最近播放时间及曲目ID稳定排序。显示封面、曲名、歌手、次数、最近播放时间；单击名称详情、封面单曲播放、右键加入歌单，不改变歌单专属顺序播放边界。

实际累计播放达到min(30秒,曲目时长50%)计一次；暂停、缓冲和拖动进度不计入有效时长，同一播放会话只记一次。重新播放／自然进入新一轮重新建立会话。不能使用音频GET、Range请求或下载次数代替听歌次数。

服务端按认证账户维护会话幂等、限流与合理性校验，采用累计及按日统计支持时间筛选，统计从功能启用后开始。网页与MusicPlayer2共用上报协议，客户端Key仅归到所属账户，不能指定其他用户；旧客户端未上报的历史不补算。账号切换、退出和Key切换隔离待发送记录，禁止串号。采用短请求及有界重试，不阻塞播放。

本功能需要数据库结构变更。实施前明确schema 8→下一schema的事务迁移、原数据快照与回退，以及更新器支持路径；不能只改版本常量或以清库重新导入代替迁移。新增只读统计与播放上报接口及网页模块，客户端增加实际播放时长采集及上报测试。具体迁移版本与接口在该阶段实施记录中固定。

## 四、手机独立低音量

当前手机断点隐藏音量控件。增加可触达的“音量”弹层及独立信号衰减，范围0–100%，不提供放大；低音量段细调，提供25%／10%／5%快捷档与静音。偏好按设备本地保存，切歌、刷新恢复与重试前应用，不能先发出原音量再调整。系统音量不变，实际在播放器输出前缩小信号。

普通HTML音量属性在部分手机浏览器受限；优先评估用户交互中启用AudioContext／MediaElementAudioSourceNode／GainNode。一个媒体元素只连接一次处理链，切歌复用；处理失败不显示虚假生效状态，不在失败时突然回到满音量。必须验证用户手势启用、锁屏／后台、蓝牙切换和播放恢复；尚未实机验证的机型不能宣称兼容。已经询问用户手机及浏览器类型，按回复落实支持范围。

官方技术依据：[MDN媒体元素处理](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/createMediaElementSource)、[MDN增益节点](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/createGain)、[Apple历史iOS媒体限制说明](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/Using_HTML5_Audio_Video/Device-SpecificConsiderations/Device-SpecificConsiderations.html)。旧平台说明只作为限制依据，实际兼容以目标浏览器验证为准。
