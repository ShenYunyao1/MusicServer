# 网页歌单顺序播放与紧凑双语歌词开发计划

2026-11-02，用户已批准方案并授权本地实施。本次不推送、不发布、不操作云端；沿用schema 8及现有媒体鉴权。

## 行为约定

歌单内从封面、右键播放或“播放全部”建立完整歌单顺序快照，从指定曲目向后播放，末首停止，不循环。自有、公开及有效订阅／分享歌单使用相同规则；全局曲库仍为单曲播放，切换到曲库曲目即清除队列。去除曲名双击播放，保留查看详情及既有选择热区，不扩大选择行为变更。

队列独立于页面、分页、搜索及勾选状态；按已保存顺序读取完整目录，分页版本不一致有界重试。后续歌单编辑不改变当前快照，重新发起播放读取新顺序。按需读取曲目详情，不预下载音频。曲目缺失／下架跳过，网络错误暂停重试；登录或来源授权失效停止并清理队列。刷新网页不自动恢复播放。

底部新增上一首／下一首、歌单名与当前位置、播放列表入口；曲库模式隐藏队列相关按钮。歌词与播放列表共用底部上方的浮层区域，互斥显示；再次点击入口、点击外部空白或Esc关闭，关闭不影响播放。切歌保持所选面板，不自动打开。

同步歌词只显示上一组／当前组／下一组；同时间戳文本保留并组成原文与译文组，不按相邻文件行猜配翻译。默认显示译文，可关闭并本机记忆。原文14px／当前17px、行高1.4，组内2–4px、组间8px，长句允许换行。首尾保留空位；进度变化立即定位。无时间轴显示“暂无同步歌词”，提供同面板文本阅读，内容以纯文本渲染。保留歌词输入大小、行数限制。

## 阶段与验收

- [ ] P01 播放队列及接续：显式播放来源、完整分页快照、自动下一首／末首停止、权限和网络错误、旧请求隔离；专项测试先红后绿。
- [ ] P02 播放器及入口：歌单播放全部、所有歌单播放入口一致、曲库隔离、取消双击播放、上下首及队列列表、互斥／外部关闭；交互回归。
- [ ] P03 紧凑双语歌词：时间戳分组、三组显示、翻译开关、无时间轴文本模式、切歌／跳转／账户清理；解析及播放器专项。
- [ ] P04 真实浏览器集成及手机布局验证，更新验收记录并本地提交；完整跨平台CI留待用户另行授权推送。

## 验收记录

实施前核对：现有online-player.js仅管理单曲，ended只刷新显示；自有歌单browse接口提供revision分页，公开／订阅具有独立读取路径。现有解析器保留重复时间戳，但播放器会定位到重复时间戳的最后一行，需要在显示层分组，避免丢失原文。现有曲名双击播放需与旧测试同步调整。
