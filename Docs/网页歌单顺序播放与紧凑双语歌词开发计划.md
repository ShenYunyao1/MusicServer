# 网页歌单顺序播放与紧凑双语歌词开发计划

2026-11-02，用户已批准方案并授权本地实施。本次不推送、不发布、不操作云端；沿用schema 8及现有媒体鉴权。

## 行为约定

歌单内从封面、右键播放或“播放全部”建立完整歌单顺序快照，从指定曲目向后播放，末首停止，不循环。自有、公开及有效订阅／分享歌单使用相同规则；全局曲库仍为单曲播放，切换到曲库曲目即清除队列。按用户实施中补充要求：曲名左键单击立即查看详情，移除行空白／歌手／专辑区域点击动作和全部双击处理；保留封面播放、既有选择热区及键盘可访问操作，不再设置400ms单双击等待。

队列独立于页面、分页、搜索及勾选状态；按已保存顺序读取完整目录，分页版本不一致有界重试。后续歌单编辑不改变当前快照，重新发起播放读取新顺序。按需读取曲目详情，不预下载音频。曲目缺失／下架跳过，网络错误暂停重试；登录或来源授权失效停止并清理队列。刷新网页不自动恢复播放。

底部新增上一首／下一首、歌单名与当前位置、播放列表入口；曲库模式隐藏队列相关按钮。歌词与播放列表共用底部上方的浮层区域，互斥显示；再次点击入口、点击外部空白或Esc关闭，关闭不影响播放。切歌保持所选面板，不自动打开。

同步歌词只显示上一组／当前组／下一组；同时间戳文本保留并组成原文与译文组，不按相邻文件行猜配翻译。默认显示译文，可关闭并本机记忆。原文14px／当前17px、行高1.4，组内2–4px、组间8px，长句允许换行。首尾保留空位；进度变化立即定位。无时间轴显示“暂无同步歌词”，提供同面板文本阅读，内容以纯文本渲染。保留歌词输入大小、行数限制。

## 阶段与验收

- [x] P01 播放队列及接续：显式播放来源、完整分页快照、自动下一首／末首停止、权限和网络错误、旧请求隔离；专项测试先红后绿。
- [x] P02 播放器及入口：歌单播放全部、所有歌单播放入口一致、曲库隔离、取消双击／行空白操作、名称单击详情、上下首及队列列表、互斥／外部关闭；交互回归。
- [x] P03 紧凑双语歌词：时间戳分组、三组显示、翻译开关、无时间轴文本模式、切歌／跳转／账户清理；解析及播放器专项。
- [x] P04 真实浏览器集成及手机布局验证，更新验收记录并本地提交；完整跨平台CI留待用户另行授权推送。

## 验收记录

实施前核对：现有online-player.js仅管理单曲，ended只刷新显示；自有歌单browse接口提供revision分页，公开／订阅具有独立读取路径。现有解析器保留重复时间戳，但播放器会定位到重复时间戳的最后一行，需要在显示层分组，避免丢失原文。现有曲名双击播放需与旧测试同步调整。

P01：新增会话专用browse/playback接口，显式区分own／public／subscription，不接受全局系统歌单；在同一读取事务内复核身份和来源权限，分页不返回歌词／私人备注。目录版本变化最多重读三次；切歌前复核来源权限。`TestPlaybackDirectoryPagingAndAccess`先404复现，修复后与既有Browse专项共4.413s通过；播放器10项契约测试通过，覆盖跨页、迟到响应、目录重读、跳过不可用、网络暂停重试与授权撤回。真实网页入口和布局待P02–P04。

P02–P04：歌单封面、右键、详情“播放预览”和“播放全部”统一携带来源；曲库始终清除队列。歌词及播放列表互斥，点击外部／Esc关闭；队列显示当前位置、支持直接选曲及前后切换。按最新补充移除全部双击监听及行空白动作，曲名立即单击详情；新增浏览器断言先复现旧双击仍打开详情，再确认修复，保留选择热区／路径多选／右键隔离及手机封面播放。

歌词保持原解析输出兼容，显示层将同时间戳不同文本稳定分组，原文与所有补充译文不丢失、相同文本去重。原文／译文允许换行，仅渲染前后共三个组；译文开关保存在本机localStorage，存储不可用时仍可正常使用。无时间轴只给提示和纯文本阅读入口，不伪造同步。关闭及退出清理曲目／歌词／队列内容，切换页面不取消当前歌词读取。

最终针对性验收：`TestPlayback*`、`TestBrowse*`与指定分享接收／撤回权限回归5.609s通过；包含105曲跨页、revision冲突、私人备注查询不可探测、公开转私有、订阅取消及邀请撤回。歌词与播放器22项Node契约通过，Go vet及JS语法／差异检查通过。实际隔离服务的在线播放器专项及新playlist-playback-ui通过，使用真实音频ended事件验证自动接续／末首停止、前后切换、队列选曲、跨页来源隔离、公开权限失效；390px手机布局、三组双语歌词、互斥／外部关闭、翻译偏好保存及账户退出清理通过。轨道选择专项通过最新单击／空白／双击规则及原热区、右键、路径选择与移动端回归。

新浏览器用例已接入现有online-player-ui，沿用Actions管理网页门禁；Go及Node用例也由既有门禁执行。尚未推送，远程完整跨平台／race／两端联调CI未执行，不宣称正式发行。测试程序和数据均隔离，未替换运行服务或改变数据库schema，未连接云端。
