# 播放器服务器歌单与按需缓存

用户已确认实施，范围为 MusicPlayer2；服务端接口沿用 0.6.1。

## 验收标准

- 服务器媒体库以歌单为播放单位，右侧曲目用于浏览；主播放器显示完整队列并按现有播放模式切歌。
- 当前曲目先校验本地缓存，仅缺失或损坏时下载；不自动预下载下一首。
- 断网时跳过未缓存曲目，单次遍历没有可播放曲目时停止；失败期间暂时抑制重复网络超时，手动刷新或重试恢复连接。
- 切换曲目/歌单及停止操作使旧任务失效，暂停不会被下载完成覆盖；关闭媒体库不取消播放任务。
- 歌单快照、标签、歌词及封面关联保留，缓存文件继续使用内容哈希，界面显示友好名称。
- 媒体库关闭重开恢复选中的歌单、曲目及滚动位置，不修改正在播放的队列。
- 刷新只更新浏览数据，下次显式播放时应用新快照。
