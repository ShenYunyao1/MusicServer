# 注册与邮件服务使用说明

2026-10-26，适用于服务器 0.20.1。实施、发行及实际验收状态见 [开发计划](注册邮箱验证与账户配额开发计划.md)。

## 首次启用

升级后旧账户（包括管理员）默认需要验证邮箱才能新上传，现有配额、曲目、歌单及只读 Key 保留。管理员可照常登录、配置邮件和管理账户，临时密码账户仍须先改密。

1. 管理员进入“系统设置 → 邮件服务”，填写服务商提供的 SMTP 主机、端口、发信地址、登录名和密码／授权码。支持 STARTTLS 与隐式 TLS，必须通过证书验证；端口按服务商要求填写。保存后密码不回显，已有凭据留空保留。
2. 填写本人可接收的测试邮箱，发送测试邮件。页面确认提交服务后检查收件箱及垃圾邮件，系统日志的“邮件”类别可查提交／失败原因。SMTP 接受邮件不代表最终收件成功；修改 SMTP 设置后须重新测试。
3. 在个人中心发送验证码并完成验证。验证码 10 分钟有效，重发间隔 60 秒，每次挑战最多尝试 5 次；未收到可刷新发送状态，投递失败稍后重试或联系管理员。
4. 需要开放注册时，进入“系统设置 → 注册与账户”，明确设置新注册默认配额，完成邮件测试后再启用注册。默认关闭，关闭后已有账户仍可验证邮箱。

使用服务商分配的发信地址或已验证域名，不需要在音乐服务器自行运行 SMTP 服务。实际凭据仅通过后台填写，不要放入 Git、聊天或编译脚本。

## 用户与配额

“用户管理 → 创建成员”只填写登录名、配额和验证要求，昵称默认同登录名，用户可在个人中心修改。配额必须明确选择限额或不限额；“需要验证邮箱后才能上传”默认勾选，管理员可在用户详情调整，修改会被审计。邮件尚未可用时，可以明确豁免指定账户，不能用 `0` 配额阻止上传，因为 `0` 表示不限额。

用户管理列表及详情提供配额编辑，个人中心显示本人用量。磁盘容量设置保留全局预留和清理策略。用量继续按原始上传者统计，管理员接管不转移历史计费归属。

自助注册填写登录名与密码，之后登录验证邮箱；注册当时的默认额度会锁定。例如默认额度从 1 GiB 改为 2 GiB，修改前注册但尚未验证的账户仍为 1 GiB。验证、更换邮箱均不重复授予额度，也不覆盖管理员已调整的额度。

更换已验证邮箱需当前密码和新邮箱验证码；成功前保留旧绑定。邮箱域名忽略大小写，本地部分保留大小写，不合并加号／点号别名。一个已验证地址只能被一个账户占用；软删除账户仍保留占用，管理员可从“用户管理 → 已删除账户占用”明确释放。

## 上传、保存与恢复

未验证且未豁免的账户可浏览／播放现有曲目，管理歌单和只读 Key；不能创建或继续上传，也不能提交旧暂存。已有续传允许查看和取消，验证后可继续符合有效期要求的任务。邮箱验证不绕过停用、首次改密、配额或磁盘预留检查。

非秘密配置及策略保存在数据库 `settings`／`meta`，不增加 SQL 表或列，schema 继续为 7。首次旧账户初始化标记、邮箱绑定及配额快照持久保存，重启不覆盖管理员豁免。

邮件凭据和主密钥保存在数据库旁 `.mail-secrets/`。Linux 目录／文件权限为 0700／0600；Windows 仅运行账户、SYSTEM 和 Administrators 可访问。正常发送任务在数据库加密保存，重启可恢复，完成／过期清理邮件负载。

普通应用备份不包含秘密目录。恢复后保留账户、邮箱绑定和配额，清除待处理验证码／邮件任务，关闭注册并要求重新配置、测试邮件服务；不会自动豁免未验证用户。不要手动清理正在使用的秘密文件。
