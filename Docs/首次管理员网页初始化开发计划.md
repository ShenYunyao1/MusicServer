# 首次管理员网页初始化

用户授权将首次启动的管理员密码设置从终端改到网页，承接 Ubuntu 云端部署。已有管理员及 schema 7 数据保持不变，终端命令保留用于离线恢复。

- [x] 服务可在无管理员时启动；扫描和暂存清理等待初始化完成。
- [x] 私有文件保存随机一次性授权码，重启仍可使用；已有管理员时关闭入口并删除授权文件。
- [x] 初始化接口校验同源、授权码、密码确认及强度，限制并发哈希；并发请求只能创建一个管理员。
- [x] 网页提供 admin 账号、密码确认和错误反馈；授权链接通过 URL fragment 传递并立即清除，不写入访问日志。
- [x] 首次安装脚本使用网页初始化，不再等待终端输入密码。
- [x] 接口、首次启动和真实浏览器回归通过；更新版本、文档并本地提交。
- [ ] 发布签名正式包，在云端验证真实更新、数据保留及首次网页初始化，用户设置正式密码后核对服务。

授权码不进入 Git、聊天或服务日志。云端当前为临时验收数据，用户正式初始化前核对并隔离。无域名阶段沿用 SSH 隧道，不开放公网 HTTP。

验收：完整 Go 测试与 go vet 通过；隔离 Chromium 完整管理端回归通过，覆盖无交互启动、授权链接清除、密码确认、一次初始化、登录及自动扫描，还覆盖现有多用户、公开订阅与指定账户分享。接口额外验证错误授权／来源、并发独占、弱密码、Argon2id、审计及停用管理员不重新开放初始化。

安装脚本通过 bash -n，网页脚本通过 Node 语法检查；runtime-layout 验证固定路径和已有账户启动通过。版本 0.15.0，schema 7；CI 和云端正式更新仍待后续验收。
