# 曲目标签打标与导入接口

2026-10-28，P03 本地实现。默认 schema 7 不启用这些标签功能，正常网页隐藏入口，正式启用仍须通过迁移安装及发行门禁。基础词典和权限见 [接口与权限](曲目标签接口与权限.md)。

## 元数据来源

私有 7→8 迁移在 P02 八张标签表之外增加 `track_tag_imports` 和 `tag_batches`；没有发行新的正式 schema 版本。

`GET /api/v2/tracks/{id}/tag-import-source` 返回 `{values, unmapped, truncated}`，只限账户会话，遵守曲目可见性。未知值保留供管理员归一，不自动创建公共词条。详情页显示待归一值，读取失败可以独立重试。

解析保留 FLAC／Ogg 的重复 GENRE 和普通 ID3v2.4 TCON 的 NUL 多值；斜杠、分号保持字面含义。其他受支持格式保留已有单值 genre。带额外压缩、不同步等不支持标志的 ID3v2.4 风格不覆盖旧导入。解析失败保留旧自动关系，已知空值可清理未被人工保护的导入。原 `Track.Genre` 和音频不回写。

导入只匹配公共风格词典主名和别名，尊重 `confirmed`／`suppressed`，不改私人或其他分组。每次最多保留 64 个来源值，每值最多 1 KiB；公共关系仍受每曲目 32 个上限约束，超出部分留下待整理标记。新上传和完整重扫会归一；手动修改 genre 视为一个值，与曲目更新同事务归一。词典调整后可完整重扫，无需重新上传音频。

## 上传确认

`/api/v2/uploads/stage/{id}/commit` 保留原顶层元数据字段，增加可选字段：

```json
{"tag_edits":{"public":{"version":1,"add_ids":[],"remove_ids":[]},"personal":{"version":1,"add_ids":[],"remove_ids":[]}}}
```

只传需要修改的作用域。schema 8 预览返回 `tag_versions:{public_version,personal_version}` 和 `genre_values`；新曲目版本为 1，去重曲目按现有 UUID 的状态，私人版本只取暂存所属账户。先应用人工标签，再归一新曲目来源。去重复用不修改已有来源，也不能绕过公共管理权限。

版本、权限、会话、邮箱或配额失败会保留暂存，回滚本次文件和标签。schema 7 不带 tag_edits 的上传保持不变；显式标签请求拒绝。原上传确认请求大小上限不变。

网页整批默认与逐首选择只保存草稿，确认入库才提交。单首草稿随现有账户范围的 IndexedDB 续传队列保存，刷新后恢复；不保存音频 Blob、凭据或会话。取消队列不创建曲目关系。

## 冻结批量任务

| 路径 | 方法 | 内容 |
| --- | --- | --- |
| `/api/v2/tag-batches` | POST | 预览：`{scope, track_ids?, query?:{q,filter}, add_ids?, remove_ids?}`，显式 ID 与 query 二选一 |
| `/api/v2/tag-batches` | GET | 本账户最近 20 个未过期任务摘要数组，不含曲目／标签集合 |
| `/api/v2/tag-batches/{id}` | GET / PATCH | 获取本人详情；PATCH `{add_ids,remove_ids}` 只改预览草稿，保留冻结 UUID 及原版本 |
| `/api/v2/tag-batches/{id}/start` | POST | 明确确认执行 |
| `/api/v2/tag-batches/{id}/cancel` | POST | 停止后续批次，不回滚之前成功批次 |
| `/api/v2/tag-batches/{id}/retry` | POST | 重读未成功项版本并回到预览，再次 start 才执行 |

全部修改要求 If-Match；动作 POST 可空体或 `{}`。批量请求最多 32 KiB，大集合建议使用 query。q／filter 复用现有基础曲库条件；后续组合条件在 P04 对接。

每任务最多 5,000 首；32 首以内全有或全无，大任务按 32 首事务分批，每批复核会话、权限和版本。UUID 集合在预览时固定，后来匹配的新曲目不纳入。小集合冲突不留下部分成功；大集合已经成功的项不重复执行。

详情含 `id/scope/state/version/total/completed/conflicts/failed/cancelled/items/common_tag_ids/partial_tag_ids/add_ids/remove_ids`。item 含 UUID、冻结版本、状态及通用错误码。任务状态为 `preview/running/completed/partial/failed/blocked/cancelled/interrupted`；单项为 `pending/completed/conflict/failed/cancelled`。异常不伪报成功。

每账户最多 10 个活跃任务，最多保留 100 个终态历史，24 小时过期。重启不自动继续写入；发现无当前进程 worker 的 running 任务会标中断，须显式 retry、预览确认。刷新或重新登录后可重开最近任务。账户删除同事务清理任务；私人任务不进入公共审计或同步通知。
