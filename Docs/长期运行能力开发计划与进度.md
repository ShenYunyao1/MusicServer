## A：备份与恢复

### 行为

- 保留快速数据库快照用途；新增完整备份任务，包含一致 SQLite 快照、当时已入库且存在的音频及相关外置资源、应用设置与逐文件大小／SHA-256 清单。原本缺失文件在清单中明确列出，不伪造完整性。
- 不打包程序、暂存、日志、其他备份、TLS 私钥或未知系统文件。应用配置来自数据库；Nginx／systemd／证书及云账号凭证须按部署清单独立备份，页面说明范围。
- 流式生成归档，单任务运行，显示阶段／字节进度，可取消。临时文件只在生成、完整性校验及同步完成后发布为可下载备份；失败不覆盖已有成功备份。已有文件发生不受应用控制的外部变更时拒绝认证该份完整备份。
- 管理员可列表、下载、删除备份，接口会话／CSRF／角色边界与现有后台一致；不在 URL 中携带秘密。
- 可配置定时及保留数量，仅清理程序生成且已完成的自动归档，保留正在下载的文件；手工备份须显式删除，不删除媒体。用户已选择自动备份默认关闭，网页可自行启用。
- 恢复使用命令行工具，解包到新的空目录，逐项验证路径、类型、大小、摘要、schema 及数据库完整性；拒绝覆盖非空目录及运行数据。恢复后保留 UUID／账户／歌单／媒体，重定位媒体根目录、撤销旧会话；不会自动启动服务或替换系统配置。
