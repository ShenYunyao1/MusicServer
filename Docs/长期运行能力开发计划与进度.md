## 总体顺序

- [ ] A：完整备份与恢复——数据库、已入库媒体及应用设置的可验证备份，任务进度、下载、定时与保留策略，独立目录恢复验证。
- [ ] B：磁盘容量与配额保护——容量面板、上传／备份低水位保护、受控清理与账户额度。
- [ ] C：网页及两端联调 CI——接入已有真实网页回归，播放器固定基线与最新候选服务器联调。
- [ ] R：上述阶段验收后按本次明确授权推送、Actions、签名 Release 验收；云端由用户网页安装。
- [ ] D：上传断点续传与队列恢复，另写实现细则后开发。
- [ ] E：普通曲库／私人歌单分页、虚拟列表及当前视图增量刷新。
- [ ] F：播放器对象级增量，减少普通歌单变化引起的快照重置，保持权限撤回边界。

数据库 schema 迁移、匿名分享、协作编辑、头像、转码及边播边缓存不在本轮发布范围；现阶段继续 schema 7，不清空现有数据。

## A：备份与恢复

### 行为

- 保留快速数据库快照用途；新增完整备份任务，包含一致 SQLite 快照、当时已入库且存在的音频及相关外置资源、应用设置与逐文件大小／SHA-256 清单。原本缺失文件在清单中明确列出，不伪造完整性。
- 不打包程序、暂存、日志、其他备份、TLS 私钥或未知系统文件。应用配置来自数据库；Nginx／systemd／证书及云账号凭证须按部署清单独立备份，页面说明范围。
- 流式生成归档，单任务运行，显示阶段／字节进度，可取消。临时文件只在生成、完整性校验及同步完成后发布为可下载备份；失败不覆盖已有成功备份。已有文件发生不受应用控制的外部变更时拒绝认证该份完整备份。
- 管理员可列表、下载、删除备份，接口会话／CSRF／角色边界与现有后台一致；不在 URL 中携带秘密。
- 可配置定时及保留数量，仅清理程序自己生成且已完成的归档，保留正在使用的文件；不删除旧手工备份或媒体。默认自动策略由用户异步选择；未回答时采用关闭、网页可启用的保守默认。
- 恢复使用命令行工具，解包到新的空目录，逐项验证路径、类型、大小、摘要、schema 及数据库完整性；拒绝覆盖非空目录及运行数据。恢复后保留 UUID／账户／歌单／媒体，重定位媒体根目录、撤销旧会话；不会自动启动服务或替换系统配置。

## B：容量与配额

- [ ] B01：Windows／Linux 磁盘空间适配及用量分类，管理页显示数据库、媒体、暂存、备份与更新占用；避免媒体根目录包含 data 时重复计数。
- [ ] B02：全站剩余空间低水位检查；上传接收／写入／确认及备份开始前检查，失败清理本任务临时文件，保留原资源。外部程序可同时占用磁盘，因此不宣称替代文件系统配额。
- [ ] B03：按原始上传者统计已入库物理文件，占用随原上传者保留；重复复用不重复计费。默认额度由用户异步选择，管理员可按账户设置；下架保留文件时不宣称空间已释放。
- [ ] B04：安全清理受管备份／更新缓存，保留当前及回退所需版本；不自动删除媒体、未知文件或操作系统目录。验证失败回滚／低空间／其他账户隔离及页面。
