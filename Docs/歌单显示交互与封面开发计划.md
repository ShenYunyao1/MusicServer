# 歌单显示、交互与封面开发计划

日期：2026-10-23。依据用户已确认方案执行；共享歌单暂不实施。

## 目标与范围

我的歌单采用整项点击、右键菜单和拖拽排序；歌单详情与全局曲库统一显示；编辑歌单改为独立页面，支持正方形封面裁剪、草稿预览及一次保存。返回入口统一放在正文左上角。保留私人歌单、个人备注、不可用占位、版本冲突检查与现有账户权限。

## 实施清单

- [x] PL01：简化歌单项，整项点击及 Enter 打开，右键／Shift+F10 菜单；桌面拖拽、触屏长按排序，显示插入位置，松手保存，拖拽不误打开。搜索期间禁用排序。歌单详情返回按钮移至正文左上角。
- [x] PL02：增加歌单封面字段与原子保存接口，复用封面资产存储；名称、简介、封面同一事务保存。验证真实图片格式、大小与尺寸，保留版本条件；封面读取依据所属歌单权限，防止跨账户读取或修改。
- [x] PL03：独立编辑页（左侧封面、右侧表单，手机上下排列）；JPEG／PNG／静态 WebP，原图最多 8 MiB／2000 万像素。固定正方形裁剪框，支持移动、缩放、重置，输出最大 1024×1024；取消裁剪不影响草稿，保存前仅本地预览。返回处理未保存草稿、保留原页面搜索与滚动位置；提交失败保留输入和裁剪结果。

- [ ] PL05：完整 Go／vet、桌面与触屏浏览器回归和截图检查；更新文档，创建本地提交，按固定编译入口生成 build/musicserver.exe，启动后核对 8080 与 LAN 的健康状态、提交号和页面资源。

## 文件与职责

- `server/internal/music/library.js`：歌单列表／详情、菜单和曲目展示。
- `server/internal/music/playlist-ui.js`（新增）：可复用排序交互、独立编辑页和裁剪草稿生命周期。
- `server/internal/music/navigation.js`：编辑页路由、返回与未保存草稿处理。
- `server/internal/music/management.js`、`index.html`、`management.css`：旧编辑入口替换、脚本入口及响应式布局。
- `server/internal/music/types.go`、`cover_store.go`、`server.go`：歌单封面信息、校验、原子保存、读取权限与静态资源注册。
- `server/internal/music/playlist_cover_test.go`、`server/tests/playlist-ui.cjs`（新增）及相关现有浏览器用例：事务、鉴权、冲突、裁剪、排序、返回、草稿取消及手机验证。

## 数据与接口

歌单增加 `cover_id`、`cover_mime`（可空），不改变曲目 UUID 或归属。新增 `PUT /api/v2/playlists/{id}/editor`，通过 multipart 提交名称、简介、可选裁剪封面／移除标记，沿用 `If-Match` 和账户会话／CSRF 校验；成功后增加歌单版本并记录变更与审计。失败不得留下半成功的元数据或封面。现有 JSON PATCH 继续用于纯元数据操作。

原图在浏览器校验和裁剪，提交的是最大 1024px 正方形 PNG；服务端再次实际解码并限制格式、字节数及尺寸。GIF、SVG、动画及损坏图片给出明确提示。预览 Blob URL 在替换、离开或退出时释放，上传和草稿不写入源码目录。

## 验收与提交

每阶段先添加有意义的行为回归，确认旧实现失败，再实现并检查相邻功能。每项仅在对应验收通过后勾选，并与代码和验证脚本一起本地提交；不提交媒体、数据库、密码、Key、日志和编译产物，不推送远程。

使用隔离程序、临时数据库和测试账户验证；不改动现有私人歌单内容。排序一次落点提交一次，冲突或失败恢复服务端顺序并提示；保存失败保留草稿，不绕过权限与版本检查。
