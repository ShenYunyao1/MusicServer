# 永久删除曲目与空账户开发计划

日期：2026-10-30。用户授权实现；本阶段本地提交，不推送或操作云端。

- [x] 管理员可永久删除已下架曲目，版本校验、清理歌单占位及关联、删除音频；正常曲目须先下架。
- [x] 已停用且没有管理／原始上传曲目、歌单和上传暂存的账户可完全删除；历史已删除身份也提供清理入口。保留审计，共同标签贡献归属转交操作管理员，不删除公共标签。
- [x] 补充权限、冲突、回滚、文件安全与界面回归；完成后本地提交，完整CI待推送执行。

文件先移到媒体根目录下扫描排除的暂存区，数据库失败则恢复；启动时根据曲目是否仍存在恢复／清理中断操作。彻底删除账户释放登录名、邮箱及配额元数据；有原始上传溯源时拒绝，不能通过接管绕开。现有软删除保持兼容，不修改数据库schema。

## 入口及接口

- 曲库维护 → 已下架曲目 → 永久删除：`DELETE /api/v2/admin/removed/{id}`，If-Match必填，仅管理员；清除所有歌单中的该曲目及备注，更新歌单版本与增量变更流；曲目标签关系由外键级联清理，保留词条。音频删除失败时事务不提交；提交后暂存文件清理失败则启动重试。共享封面和外部歌词等旁挂文件不随单曲删除，避免误删其他曲目使用的资源。
- 用户管理 → 已停用账户行／账户详情 → 完全删除；用户管理 → 已删除账户占用 → 完全删除：`DELETE /api/v2/admin/users/{id}/purge`，If-Match必填。当前管理员、启用账户、有资产账户均不能完全删除。进行中的分片和已校验待入库上传视为资产；已取消或已完成且无待入库记录的上传检查点不阻塞，随账户清理。
- 现有“删除账户”继续保留溯源身份；完全删除要求原始上传曲目也已永久删除，接管不改变该判定。审计历史保留UUID身份，不随登录名复用而转归新用户。
