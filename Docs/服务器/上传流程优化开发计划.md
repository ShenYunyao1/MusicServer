# 上传流程优化开发计划

日期：2026-10-30。用户批准按顺序完成并发布；兼容当前schema 8数据库、旧续传检查点和原有上传接口。本次发行同时包含已本地完成的曲目／空账户永久删除功能。不连接云端。

## 阶段与完成标准

- [x] U01 统一交互：开始上传默认自动校验入库，可切换入库前确认；统一阶段、批量失败重试、结果汇总；账户切换及取消隔离，成功任务不重复入库。必要专项及真实网页验收后本地提交。
- [x] U02 文件与流水线：续传文件直接复用至校验／入库，安全的同卷链接／移动及回退，重复曲目提前识别、最终权限额度复核保留；预检查与实际阶段查询；1个传输可与上一首校验重叠，可选2个传输。覆盖崩溃恢复、幂等和旧接口，再本地提交。
- [x] U03 批量与流畅度：摘要Worker有界处理及回退、本地解析限流、队列分页、批量标签及目标歌单、失败集中处理；保留草稿不持久化音频。验证大队列、附件及标签、旧任务恢复，再本地提交。
- [x] U04 正式发行：核对版本／发行说明／干净跟踪工作区，推送main及一致标签，完整Actions通过，独立核验正式资产签名／摘要／版本后记录交付。

## 文件与接口边界

前端 `management.js`、`upload-resume.js`、`upload-progress.js` 及新增上传队列模块负责交互、调度与草稿。Worker独立模块负责分片摘要，保持 `resumeHash` 原函数契约和非安全上下文回退。批量标签复用现有 `tag-editor.js` 上传默认值机制，不覆盖已有全站曲目资料。

后台 `upload_resume.go`、`staging.go` 及新增辅助模块负责预检查、阶段查询、减少文件复制和提前重复识别。上传前检查只作提示，最终事务继续执行身份、权限、额度、标签版本及下架保护。客户端摘要不能作为文件拥有证明；本期重复识别依赖实际收到文件的服务端摘要，不提供凭摘要免上传接口。

拟新增 `GET /api/v2/uploads/preflight`：登录账户的 `max_upload_bytes`、`used_bytes`、`limit_bytes`、`upload_allowed`；`GET /api/v2/uploads/resumable/{id}/status`：本人任务 `phase`（uploading/queued/probing/metadata/ready）及必要检查点信息，校验长请求期间仍可查询；禁止跨用户和Key读取。原finish及commit契约保留。错误、旧任务、浏览器无Worker、刷新后重新选择原文件都需可恢复。

本地针对性测试、Go vet、独立程序真实网页；完整跨平台／race／systemd／播放器联调交Actions。性能提升用减少实际复制及阶段耗时验证，不承诺突破带宽上限。不将后台计算显示为虚构百分比。

## U02 验收

新增本人预检查和免finish锁阶段查询；同卷使用硬链接发布并清理暂存链接，不支持时受限复制。通过同inode及中断发布恢复验证；O_EXCL碰撞和符号链接源先复现失败再修正，保证只清理自己创建的文件。对服务端实际收到的字节计算摘要，只有严格验证过的重复字节跳过ffprobe，旧扫描数据首次仍严格验证。最终事务保留额度、标签版本、归属和下架约束；重复复用不受新文件额度不足影响。

后台上传／续传／Stage／TagUpload专项25.110s及vet通过；碰撞调用链和源路径专项修正后，整合状态的 `go test ./internal/music -run 'TestUploadPipeline|TestResumable|TestUploadStage|TestTagUpload' -count=1 -timeout 120s` 通过（13.130s）。真实网页延迟finish后第二首仍完成传输，默认自动／手动确认／重复／失败汇总通过。`node tests/upload-flow-contract.cjs` 覆盖1／2传输及最多并发数+2活动任务、暂停继续、取消、账户切换、迟到401、旧确认批次和重入；`node tests/resumable-ui.cjs` 13项续传专项通过。后台阶段状态不使用虚构百分比。摘要Worker独立文件已随静态资源接入，批量优化及完整回归在U03／U04完成。

## U03 验收

摘要使用单Worker、最多保留4个4 MiB块，不转移上传原缓冲区，支持非安全HTTP及Worker失效回退；独立真实浏览器专项通过，实际服务器网页也确认Worker成功运行。本地元数据最多2个解析任务，附件变化按代际重新解析；队列按50项分页并支持未完成／失败／已完成筛选。批量作者／专辑和既有本批默认标签应用到未完成项；目标歌单只列本人可编辑歌单，上传成功后增量加入，歌单失败单独保留待重试草稿，不重传音频。

新增事务内24小时提交回执和本人查询接口 `GET /api/v2/uploads/receipts/{stageID}`：提交响应丢失时恢复已提交结果，不重复应用标签。新入库、提前重复、最终竞态重复均同事务写回执；完全删除账户清理回执，旧schema和API保持兼容。回执／Stage／TagUpload／Resumable专项14.917s；最终 `^TestUploadReceipt|^TestPermanent` 6.300s及Go vet通过。

`upload-flow-contract.cjs`、`upload-batch-contract.cjs`、`upload-hash-ui.cjs` 通过；批量专项先复现远端任务已删导致本地已提交任务丢失、旧重试启动新账户任务、附件变更后解析不重启三项，再修复通过。续传13项、本地元数据41项全部通过。最终上传真实专项涵盖延迟校验流水线、Worker、批量资料及歌单、真实提交成功后丢响应、歌单503失败后刷新并只重试歌单、120项队列只渲染50项和390px无横向溢出。

最终隔离程序的完整 `node tests/management-ui.cjs` 通过，包括实际限速进度、原附件／曲目／歌单交互、个人中心相邻入口、两端权限、账户及曲目永久删除、备份恢复、容量和真实暂停／刷新续传。诊断截图和测试数据均在忽略或系统临时目录。新增门禁已接入现有Actions管理网页作业，完整远程CI和正式资产验收仍待U04。
