## 兼容与发行约束

- 已有安装的数据库、媒体、配置、会话、邮件加密、恢复标记以及浏览器上传队列需要持续可读，按实际持久化契约逐项审查。
- 已发行更新器对 `release-manifest.json`、`musicserver-*` 包名及包内文件名采用严格白名单，重命名通过兼容资产和入口衔接，签名和文件校验继续覆盖实际下载资产。
- Linux 现有安装的受管目录、服务账户、systemd 单元和独立 worker 路径属于运行配置。沿用现有更新事务完成主程序更新，人工维护事项写入随包指南。
- 历史发行说明、审计证据和旧版本基线按原身份保留。当前文档补充新名称与兼容名称的对应关系。
- 数据库验收以 schema 8 及其后续阶段为范围。阶段完成后本地提交，完整回归由后续 Actions 执行。远程仓库改名核查与源码推送、正式发行分别记录。
