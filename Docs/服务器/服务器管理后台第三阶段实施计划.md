# 服务器管理后台第三阶段实施计划

## 目标

- 将歌单和曲目编辑、删除统一到右键菜单。
- 曲目管理支持多选后通过“添加至”菜单加入歌单。
- 将曲目筛选控件移动到搜索框下方的独立行。
- 完善上传队列的元数据预览、编辑和上传状态。
- 保持 API Key 歌单复选框授权及现有服务端 API 兼容。

## 阶段

1. 右键菜单、曲目多选和筛选布局。
2. 上传队列的文件信息、字段编辑和失败重试。
3. 设置与服务端配置入口整理。
4. 构建、脚本语法检查和浏览器验证。

## 完成标准

- 歌单、曲目列表不再显示编辑按钮。
- 右键歌单可编辑或删除；右键曲目可编辑、删除，并可将当前多选曲目加入任意歌单。
- 搜索框和筛选行独立显示，筛选支持全部曲目和孤立曲目。
- 上传队列可在上传前修改基本元数据，上传成功或失败状态清晰可见。
- `server/build.ps1` 和前端脚本语法检查通过。
