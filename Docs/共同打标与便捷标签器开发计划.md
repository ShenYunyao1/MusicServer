# 共同打标与便捷标签器开发计划

日期：2026-10-29。用户确认按 Eagle 风格参考实现便捷标签器，并开放普通用户参与全站公共整理。本轮只本地开发及提交，不推送、不发布、不操作云端。使用编写计划、执行计划及子代理开发技能，将后端权限与新标签器界面分开实施并集中验收。

## 范围与交互

普通用户可为全站可见曲目添加／移除公共标签，创建公共词条；公共词条重命名、别名维护、合并、删除以及分组管理仍归管理员。个人标签仅本人可见，不扩大 Key 权限。已有 schema 8 数据原样保留。

右侧非模态标签器打开时曲目列表仍可选择、搜索及翻页，自动让出空间；显示当前选择，支持固定对象，未固定时跟随选择。外侧空白关闭，固定后保留。上传草稿及大规模全部匹配结果继续走明确保存／任务确认，不冒充即时原子操作。

名称与别名优先复用，按完全匹配、前缀、包含排序；别名命中显示标准名及匹配信息，不推断未知同义词。分组／公共个人作用域始终明确。方向键选项、Enter 选择；无匹配时 Enter 创建并添加。有相似结果时创建须明确选取创建行。请求未完成、失败或输入法确认期间禁止创建；同名并发冲突重新搜索复用。

单曲和小范围点击即保存；部分拥有点击补齐，全有移除使用明确按钮。操作冻结当时目标及版本；结果可撤销，撤销只还原本次真正变化且拒绝覆盖后续修改。大集合保留原有批量任务。显示当前已有、最近使用标签，最近使用按账户隔离并有界保存。

## T01 验收

普通用户公共创建、全站绑定及搜索排序已先红复现，再通过修正；公共创建不允许成员夹带别名，避免绕过词典治理。`go test ./internal/music -run 'TestCommunity|TestTagSearchRanks|TestTagDictionary|TestTrackTag|TestTagBatch|TestTagUpload' -count=1 -timeout 180s` 通过（34.195s），`go vet ./internal/music` 通过。上传去重复用仍保留原 UUID、摘要、所有者及上传者；私人作用域和原有会话／Key 边界不变。

## T02–T04 验收及使用

在曲库单曲或多选右键“管理标签”，32 首以内打开右侧标签器；桌面让出曲库宽度，手机以底部面板保留上方列表。固定前跟随勾选，固定后对象不随翻页变化。搜索匹配别名显示标准名，不创建重复标签；无结果回车创建，有相似结果须明确选择创建项。已有标签点击补齐，“移除”明确执行删除绑定。选择其他曲目、分页或搜索可以继续操作，无遮罩。

小范围逐首保存并显示实际成功数量，部分失败仅允许撤销成功子集，不宣称跨曲目原子操作。撤销使用每首操作后版本，后续任何同作用域修改会拒绝覆盖。大范围仍使用原批量预览与任务确认；上传草稿仍明确保存后入库。近期标签按账户和作用域保存最多 16 项，优先显示当前有效词典页中的近期项；当前已绑定标签从曲目视图独立合并，不受搜索前 50 项限制。词典长列表通过输入搜索缩小范围。

曲库“未标签”表示没有公共标签，可与现有条件组合；即时打标后复用修订刷新，已分类的曲目退出结果。普通分页刷新保留当前页，以新基线完整替换该页；末页空了退回有效页，避免混用旧分页快照。未固定的选择随可见范围变化，撤销仍冻结实际成功的原始目标。
