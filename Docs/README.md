# 项目文档

## 分类入口

- [播放器文档](播放器/README.md) 收录 Windows 播放器的适配计划、早期联调记录与辅助脚本，并链接客户端独立仓库中的当前使用、构建和发布文档。
- [服务器文档](服务器/README.md) 收录服务端、网页管理界面、网页在线播放器、接口协议、数据库升级及缺陷审查记录。
- [开发提交与版本发布流程](开发提交与版本发布流程.md) 是两端共用的工作约定，保留在本目录。

## 维护约定

- 新文档按所属项目放入对应目录。网页在线播放器归入服务器，Windows 播放器归入播放器。
- 跨端协议集中维护于 [服务器协议目录](服务器/协议/)，可执行契约保留在 [contracts](../contracts/README.md)。两端文档通过链接引用协议。
- 客户端独立仓库内的 `MusicPlayer2/Documents/` 继续维护该仓库的使用与开发记录，本目录通过索引关联。
- 保留历史文件名、日期、验收结果与进度勾选。阅读时结合文档记录日期及当前源码判断适用范围。
- 文档链接使用相对路径。移动文件时同步检查正文引用、脚本路径、仓库说明、`AGENTS.md` 和 Actions 路径过滤。
- 个人配置记录留在本地，密钥、密码、运行数据和构建产物继续按仓库约定管理。
- 日志与截图按所属项目集中放在 `播放器/archive/` 或 `服务器/archive/`，下分 `logs/` 与 `screenshots/`。各归档目录整体忽略，`Docs` 内所有层级的 `.log` 与 `.png` 文件也受忽略规则保护。
