# 网页社区实时增量刷新开发计划

日期：2026-10-24。状态：已授权本地开发，尚未推送／发布。适用网页公开歌单、订阅、收到的邀请及作者分享设置；播放器继续每小时刷新。

## 行为与范围

- 正常联网、页面可见时以 1–3 秒更新为目标。每个标签页使用一条 SSE 连接；通知合并后拉取相关视图差异，不重载整个曲库。
- 新邀请更新角标；接受／拒绝／撤回更新邀请与订阅；转私有、源删除、作者停用及时清理可读内容并展示失效状态；恢复后重新可用。
- 公开搜索、分页、排序变化以当前分页重新计算差异，响应提供变化项、移除 ID 和新顺序。保留滚动、搜索和未保存输入，避免闪空列表。
- 后台页关闭连接与计时器；重新可见时补取差异。异常时自动重连并降级为可见页面每 60 秒检查，保留手动刷新。
- 仅会话可用，首次改密门禁不变，增量 POST 校验 CSRF；通知与快照按当前用户／会话和视图鉴权，不能读取他人邀请。连接定期复核会话，心跳不更新最近活动；登出／禁用／改密后终止。

## 实现选择

复用已有 SQLite revision、public_revision 及审计序号，在事务提交成功后唤醒连接，失败回滚不通知。不新增业务表，不调整 schema；不改变播放器的同步协议或刷新周期。

增量基线为服务端有界、短期的随机游标缓存，绑定账户、会话、认证版本及视图参数，只存记录指纹与分页元数据，不存密码／Key。数据库仍保存权威业务状态；比较最新投影与基线返回最终新增、修改、移除和顺序，断线期间多次变更合并为最终状态。游标过期、缓存淘汰或服务器重启返回 reset，重新读取当前视图。这是当前状态增量同步，不提供邀请历史事件回放。

SSE 发送“视图已变化”通知，业务数据由 `POST /api/v2/community/sync` 返回；`GET /api/v2/community/events` 使用同源 Cookie 和受限视图参数。只在本账户可见投影变化时发送业务通知。读事务不重复触发业务通知。限制连接数量、差异基线容量、请求参数和写入等待，慢连接不会阻塞其他请求。
