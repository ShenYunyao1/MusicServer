# 曲目标签接口与权限

2026-10-27，P02 本地实现。本文供后续网页、导入和筛选开发使用。

## 启用边界

默认服务器仍使用 schema 7，以下接口在正常库返回 `503 TAGS_UNAVAILABLE`，不会自动建表或升级数据库。schema 8 标签 DDL 已加入包内 7→8 迁移，由隔离测试库验证；正式启用须经过开发计划中的桥接安装及发行门禁。不要手动修改正式库的 schema 标记。

本阶段没有标签网页、导入、批量任务或筛选功能；`saved_track_filters` 仅建表，接口在 P04 实现。原曲目对象和播放器协议未增加私人字段。

## 权限和数据规则

- 全部接口要求有效账户会话；API Key 返回 403。写请求沿用同源检查和 `X-CSRF-Token`，事务内再次检查账户、会话有效期、首次改密及认证版本。编辑标签无需通过邮箱上传资格校验。
- 公共词典、分组由管理员维护；成员可以读取公共词典。曲目管理者和管理员可以修改该曲目的公共标签绑定。
- 个人词典和关系只属于当前会话账户；不能传入他人用户 ID，管理员也不能读取他人的私人整理。其他账户访问个人词条 ID 返回 404。
- 停用后数据保留，重新启用后需重新登录；删除账户清理私人词典、绑定、状态和保存条件。接管曲目保留公共绑定，不转移个人整理，不改变原始上传者。
- 私人操作不改变全局曲目修订号、不发送公共通知；审计只记录操作及用户作用域，不记录标签名称、别名、私人标签 ID 或对应曲目 ID。公共绑定变更才更新受影响曲目版本和同步记录。

分组内置 ID：`genre`、`language`、`version`、`mood`、`scene`、`custom`。管理员可新增、重命名、排序自定义分组；内置分组不能删除，有词条（含墓碑）的自定义分组也不能删除。

标签使用 UUID；名称显示保留大小写，唯一键采用 NFC、Unicode case folding 和空白折叠；拒绝控制／格式字符。主名称与别名共享同一“作用域＋分组”的唯一命名空间。公共与个人词条可同名。

当前边界：名称／别名 64 个 Unicode 字符，每标签 32 个别名，每曲目每作用域 32 个标签；公共有效词条 10,000 个，每账户个人有效词条 2,000 个，分组总数 100 个，每页最多 100 个，请求 JSON 最多 32 KiB，一次合并最多处理 5,000 首受源标签影响的曲目。超限明确失败并回滚。

## 接口

返回 JSON，不缓存。创建成功为 201，读取／修改／合并为 200，删除为 204。

| 路径 | 方法 | 内容 |
| --- | --- | --- |
| `/api/v2/tag-groups` | GET | 分组数组，含 `id/name/sort_order/builtin/version` |
| `/api/v2/tag-groups` | POST | `{name, sort_order}` |
| `/api/v2/tag-groups/{id}` | PATCH / DELETE | 修改 `{name?, sort_order?}` 或删除自定义分组 |
| `/api/v2/tags` | GET | 分页查询词典 |
| `/api/v2/tags` | POST | `{scope, group_id, name, aliases?}`，scope 必须明确为 `public` 或 `personal` |
| `/api/v2/tags/{id}` | GET / PATCH / DELETE | 读取词条、修改 `{name?, aliases?}` 或删除未被引用的词条 |
| `/api/v2/tags/{id}/merge` | POST | `{target_id, target_version}`，源版本放 `If-Match` |
| `/api/v2/tracks/{id}/tags` | GET / PATCH | 读取当前账户可见标签；修改 `{scope, add_ids?, remove_ids?}` |

词典查询仅接受 `scope`、`group_id`、`q`、`offset`、`limit`，不接受重复参数或 `user_id`。默认 public、offset 0、limit 50，limit 1–100，offset 0–1,000,000，搜索最多 64 字符，可匹配主名和别名。响应 `{items, total, offset, limit, revision}`；revision 是相应作用域修订号，供后续增量通知使用。其他接口不接受查询参数。

词条含 `id/group_id/scope/name/aliases/version/deleted/merged_into?/created_at/updated_at`。有效列表不返回墓碑；按 ID 读取可返回删除或合并记录，但仍执行原作用域权限检查。新建分组和词条、读取／修改单个词条、修改分组会返回对应版本的 ETag。

## 版本、合并与来源保护

PATCH、DELETE 和合并均要求 `If-Match`，接受正整数或带双引号的正整数。缺失返回 428，格式错误返回 400，版本过期返回 409。合并同时要求目标版本，缺失也返回 428。版本冲突时需重新读取，不能自动覆盖。

曲目标签响应为 `{public, personal, public_version, personal_version}`。两个作用域独立计数，无历史状态时版本为 1；修改时传对应作用域版本，不使用曲目通用版本。真正发生变化才增加版本，重复相同操作不产生新修订。公共手工添加记录 `confirmed`，手工移除记录 `suppressed`，为 P03 重扫保护提供基础；个人操作独立保存。音频、路径、摘要、UUID、原 genre 不被改写。

合并只能在同分组、同作用域及同所有者内进行。源名称和别名保留到目标，源 UUID 作为 `deleted=true`、`merged_into=目标ID` 的墓碑；旧重定向同时拉平。人工确认优先于忽略，忽略优先于未确认的导入。合并不静默丢弃别名；别名或曲目上限超出时整事务拒绝。

删除有关系、覆盖记录、合并引用或保存条件引用的词条返回 `409 TAG_IN_USE`，防止丢失重扫保护或扩大筛选范围。所有修改均在单个有界事务中完成。

错误仅返回稳定代码和通用说明，不暴露 SQL 或私人词条内容：`AUTH_INVALID`、`SESSION_REQUIRED`、`CSRF_DENIED`、`NOT_FOUND`、`TAG_FORBIDDEN`、`TAG_INVALID`、`TAG_NAME_EXISTS`、`TAG_IN_USE`、`TAG_LIMIT`、`VERSION_REQUIRED`、`VERSION_CONFLICT`、`TAGS_UNAVAILABLE`、`TAG_FAILED`。
