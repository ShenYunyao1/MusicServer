MusicServer 下一版开发说明 — schema 9（尚未正式发行）

当前开发树目标为 schema 9，新增个人常听统计、歌词折叠／展开浏览、网页音量衰减和上传目标歌单。已有 schema 8 数据保留，升级前必须先完成正式 schema 8 桥接主程序及独立 worker 维护，再安装更高版本的 schema 9 发行。桥接版本尚未锁定时禁止正式发布 schema 9；详见随包 `deploy/schema9-upgrade.md`。下方为上一正式 0.21.14 的功能记录，不能当作当前升级路径。

开发中的审查修复：公开及订阅歌单详情实时投影改为当前页摘要，搜索覆盖整份歌单；升级后需刷新网页以载入配套分页界面。歌单完整顺序播放和播放器 API 保持独立。浏览基线采用增量计数，公开播放分页绑定来源歌单版本；数据库使用 WAL 与专用只读连接、封面索引及轻量搜索投影。现有数据库无须重新导入。

第二轮本地修复纳入封面和独立歌词额度：同账户按内容去重、跨账户分别计入，音频内嵌附件不重复收费，个人歌单封面也计费；存量超额资产保留，新增及修改原子复核。上传预检统一已入库／暂存／续传／在途口径，硬链接不重复计物理空间，元数据预算增量维护。另修复订阅搜索实时失效、备份完成窗口／时间戳判断、空账户预览清理及词典历史容量。管理员自己的读取不占写锁，访问审计不唤醒全站；会话撤销仍及时通知。邮件孤儿凭据自动安全清理并显示失败警告；恢复权限错误不再冒充活动锁。开发包不再签名，正式签名必须通过完整发行文案／身份及桥接门禁。

上传准入合并已入库、暂存及续传预留额度，续传晋升不重复计费；重复文件接收前也需足够临时额度。单次请求保留空闲期限并增加 30 分钟读取上限，分块上传可继续；容量失败不再被校验冷却遮蔽。恢复预览过期后可重新选择目标；旧已入库任务加入歌单重试不重新传音频。歌词容器焦点与详情／播放异步状态独立。

完整备份先冻结校验媒体副本，再压缩，需要额外媒体暂存空间；变化／缺失文件以警告列入清单，其余数据库备份仍可恢复。新增 `musicserver backup cleanup --parent /path/to/parent`，显式清理指定父目录下无人持锁的受管理恢复暂存，保留未知目录及零字节锁文件。已完成备份取消返回冲突且不写虚假取消审计。邮件设置的凭据文件操作移出写锁；公共词典保留合并重定向，贡献限流使用准确 Retry-After，墓碑独立维护。

本轮本地核查修复、Go／vet 和网页回归已完成；正式发行仍需完整 Actions、真实签名 schema 8 桥接资产与 Release 验收。正式打包会机器校验发行说明版本及 schema，拒绝当前开发态模板；本文件不是已发行版本的声明。

- 歌单支持顺序播放，从指定曲目向后接续，末首停止；新增“播放全部”、上一首／下一首及播放列表选曲。自有、公开、有效订阅及只读分享歌单统一支持，全局曲库仍为单曲播放。
- 队列读取完整歌单的已保存顺序，不受分页、搜索、勾选或页面切换影响；歌单后续编辑不会打乱当前队列快照。目录变化有界重读，切歌前复核来源权限，跳过已知不可用曲目，网络错误暂停并允许重试。
- 曲名改为左键单击查看详情，移除行空白／歌手／专辑区域点击及全部双击动作；封面播放、复选框热区、路径多选及右键操作保留。
- 弹窗打开时立即隐藏页面的选中数量浮窗，消除单击立即打开详情时等待下一动画帧造成的短暂显示冲突。
- 歌词与播放列表互斥显示，再次点击入口、点击外部空白或按Esc收起；切歌保持当前面板，关闭面板不影响播放。
- 同步歌词仅显示上一组、当前组、下一组，支持同时间戳原文＋译文，长句自动换行、缩小间距。译文默认开启，可关闭并记住本机偏好；无时间轴歌词提供纯文本阅读入口。
- 当前发行验收关注 schema 8→桥接 8→9 数据保留、实际 systemd 更新及失败回退、网页和两个固定播放器版本联调。历史 schema 7 不再作为独立构建或播放器联调矩阵。正式版本号和桥接资产需在发行准备阶段确定。

安装说明：先备份数据；Windows停服后替换验签通过的固定名称程序，保留原运行数据。已配置更新器的Linux安装可检查并确认更新。首次安装使用本版程序，通过网页设置管理员。播放器客户端本次没有新版本。
