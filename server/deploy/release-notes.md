MusicServer 0.17.0

本次发行包含个人中心、统一歌单编辑和网页社区实时增量刷新。

- 新增个人中心：本人修改昵称、修改密码及管理有效登录，支持退出指定登录或其他全部登录；修改密码后浏览器重新登录，原播放器 Key 保留。
- 统一昵称展示，分享邀请使用昵称及唯一登录名区分同名账户；账户 UUID、资源归属及 Key 授权保持不变。
- 新建歌单使用与已有歌单编辑相同的完整页面，名称、简介、可见性与裁剪封面一次保存；失败保留草稿，取消不会创建歌单。
- 公开歌单、订阅及详情、收到的邀请和作者分享设置通过 SSE 通知并读取当前视图增量；邀请页签显示待处理数量，普通联网以 1–3 秒更新为目标。
- 保留无变化卡片、滚动、搜索选区和分享输入；隐藏标签页停连，恢复联网或回前台后补取，连接异常或不支持 SSE 时每分钟补查，继续支持手动刷新。
- 增量游标绑定账户、会话和视图，权限变化清理不可读内容；复核修正下架／缺失曲目信息遮蔽、取消及重新订阅后的邀请按钮状态。播放器仍保持每小时刷新。
- schema 保持 7，无需迁移数据库；保留账户、Key、曲目、歌单和订阅。重启后需要重新登录网页，若页面仍显示旧界面请强制刷新。

Windows 支持检查和手工替换程序；网页自动安装仍需 Ubuntu 独立更新器。无需调整既有部署目录；SSE 需保留 Nginx 模板已有的关闭代理缓冲及读取超时配置。网页更新不替换 Nginx 或其他系统配置。

已有 0.14.0/0.15.0 部署须先通过 SSH 将独立 root 更新器升级至 0.15.1 或更新版本，以修正 UMask=0027 下的程序权限问题；网页安装只更新主程序。已部署 0.15.1 更新器的环境可继续使用。主程序更新不会修改 root 服务模板。
