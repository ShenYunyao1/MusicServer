MusicServer 0.16.0

- 曲库操作统一右键、键盘和触屏长按菜单，移除顶部批量栏及行操作按钮，右键不会使列表下移。
- 上传显示真实字节、速率、百分比和独立服务器等待；上传连接不再排在封面下载之后，后续匹配封面只上传附件。
- 音频只探测一次并复用结果，暂存复制和验证移出全局锁，最多两个验证任务并行；输出接收、排队、探测和元数据等分段耗时。
- 管理导航新增系统日志，支持级别／类别／搜索、分页、暂停及可见时增量更新。日志限量轮转并从重启恢复，使用预定义事件与受限字段，不包含密码、完整 Key、Cookie 或请求正文。
- schema 保持 7，账户、Key、曲目和歌单保持原有数据。

Windows 支持检查和手工替换程序；网页自动安装仍需 Ubuntu 独立更新器。日志是运行诊断，不替代数据库操作审计。

已有 0.14.0/0.15.0 部署须先通过 SSH 将独立 root 更新器升级至 0.15.1 或更新版本，以修正 UMask=0027 下的程序权限问题；网页安装只更新主程序。已部署 0.15.1 更新器的环境可继续使用。主程序更新不会修改 root 服务模板。
