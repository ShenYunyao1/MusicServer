MusicServer 0.21.6 — 个人中心重构

本版继续使用 schema 8，保留现有账户、密码、头像、播放器 Key、曲目、歌单、邮箱及容量设置。已运行 schema 8 的安装可在网页检查并确认更新，不需要数据库迁移或重复维护更新器；升级后重新登录并刷新网页。

新增与优化：

- 个人中心分为“基本资料”“存储与上传”“账户安全”“登录管理”，页面只读展示。顶部集中显示账户摘要和容量入口，容量独立显示已用、额度、剩余及上传状态；不限额不显示百分比。
- “编辑资料”弹窗统一修改昵称与头像，裁剪只更新本地预览，保存时同一事务提交。用户或头像版本冲突、图片错误和写入失败均不会留下半保存状态。
- 邮箱绑定／更换／验证与密码修改各自使用独立弹窗；关闭时移除表单并清理密码、验证码和临时图片，邮箱待验证挑战保留在服务器，重开可继续验证。
- 弹窗有实际草稿时，取消／Escape／点击外侧使用站内“放弃修改／继续编辑”确认；保存中禁止关闭。弹窗关闭后正常切换页签或页面不再触发个人中心“未保存修改”提示，浏览器刷新／关闭保护仅在弹窗有真实草稿时启用。
- 修复迟到身份响应回退已保存昵称、快捷改密路由还原、版本冲突后重新读取意图丢失等边界；保留首次强制改密、邮箱上传资格、会话退出及改密后Key保留规则。
- 提供桌面和手机布局，改动沿用现有权限；普通账户只能管理本人的资料、邮箱和登录状态。

旧 schema 7 的 Linux/systemd 安装升级步骤：

1. 保存完整备份，先安装正式 0.20.3／schema 7 桥接主程序。
2. 使用已验签的 0.20.3 Linux 包，由用户执行其 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3`，核验能力支持 schema 7、8 及 7→8。
3. 完成后在网页检查并安装 0.21.6。新程序执行完整性／外键／空间预检、旧格式快照及事务迁移，失败按匹配旧程序／旧库回退。
4. latest 已前进时，按包内 `deploy/schema8-upgrade.md` 提交固定桥接版本；该指南包含验签及完整命令。不要用 bootstrap install.sh 覆盖已有安装，不让旧程序直接读取 schema 8 库。

首次安装直接使用 0.21.6。Windows 原有安装备份并停服后替换已验证程序，保留原数据启动，无 Linux root 工具维护步骤。历史 schema 1–6 或无版本库仍拒绝自动迁移，不要手改格式标记。

发布本身不操作实际服务器，维护及安装由用户自行执行。
