MusicServer 0.21.9 — 在线播放器、歌词与选择体验

本版继续使用 schema 8，保留现有账户、密码、头像、播放器 Key、曲目 UUID、歌单、邮箱、配额及上传续传检查点。已运行 schema 8 的安装可在网页检查并确认更新，不需要重新导入数据库或重复维护更新器；升级后刷新网页。

新增与优化：

- 底部在线播放器采用圆角封面、曲名／歌手／专辑、播放暂停、音量及进度条布局，展示真实已播放时间和总时长，支持拖动定位。桌面与手机布局独立适配。
- “歌词”按钮常显，在播放器上方展开可收起面板。LRC支持同步高亮、自动滚动及点击歌词定位，纯文本逐行展示；手动滚动后可回到当前歌词。
- 无歌词、加载、读取失败分别提示；歌词和音频失败可重试。切歌、关闭与退出账户取消旧读取，清理封面对象与歌词，迟到响应不覆盖新曲目。
- 手机与桌面均可单击曲目封面播放，封面常显播放标记；缺失／下架曲目禁播，信息区可打开详情，桌面保留名称双击播放。
- 扩大现有复选框热区：从曲目行最左侧到封面左缘整块立即勾选，不新增选择列；桌面路径多选继续可用。空白双击不再切换选择，歌单序号手柄位于封面右侧，与勾选区分离。
- 选中数量改为内容区导航侧悬浮卡，随导航展开／收起移动，桌面滚动保持固定；手机在内容上方显示，避开整个底部播放器。无选择时隐藏，支持清空；弹窗内的计数仍留在弹窗。
- 播放器沿用现有会话权限与音频内核，本版不增加播放队列／上一首／下一首；手机通过系统音量键调节声音。

旧 schema 7 的 Linux/systemd 安装升级步骤：

1. 保存完整备份，先安装正式 0.20.3／schema 7 桥接主程序。
2. 使用已验签的 0.20.3 Linux 包，由用户执行其 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3`，核验能力支持 schema 7、8 及 7→8。
3. 完成后在网页检查并安装 0.21.9。新程序执行完整性／外键／空间预检、旧格式快照及事务迁移，失败按匹配旧程序／旧库回退。
4. latest 已前进时，按包内 `deploy/schema8-upgrade.md` 提交固定桥接版本；该指南包含验签及完整命令。不要用 bootstrap install.sh 覆盖已有安装，不让旧程序直接读取 schema 8 库。

首次安装直接使用 0.21.9。Windows 原有安装备份并停服后替换已验证程序，保留原数据启动，无 Linux root 工具维护步骤。历史 schema 1–6 或无版本库仍拒绝自动迁移，不要手改格式标记。

发布本身不操作实际服务器，维护及安装由用户自行执行。
