MusicServer 0.21.2 — 共同打标与便捷标签器

本版继续使用 schema 8，保留现有数据库、账户、密码、API Key、曲目 UUID、媒体、歌单、订阅邀请及个人整理。已安装 0.21.1／schema 8 的用户可在网页检查更新并确认安装，不需要重复维护更新器或迁移数据库；更新后重新登录并刷新网页。

新增与优化：

- 普通用户可以给全站可见曲目添加／移除公共标签，并创建公共词条。公共词条改名、别名、合并、删除与分组管理仍由管理员负责；个人标签仅本人可见。
- 右键“管理标签”打开非模态标签器，32 首以内可即时保存。标签器打开时仍能搜索、翻页和选择曲目，支持固定对象、公共／个人切换、分组及近期标签。
- 搜索名称与已配置别名，优先复用标准词条，例如输入“日文”可匹配别名对应的“日语”。方向键选择，回车添加；没有结果时回车创建，有相似结果时明确选择创建项。中文输入法确认、搜索失败及请求期间不会误创建。
- 小范围操作冻结当时目标，明确显示成功数量和部分失败；可撤销实际成功项，后续版本变化时拒绝覆盖。上传草稿和大规模批量任务继续明确保存／确认，不自动提交。
- 曲库新增“未标签”快捷筛选，默认没有公共标签，可叠加搜索及其他条件；打标后即时更新结果，正常分页保留当前页，空末页退回有效页。
- 筛选、详情和普通编辑弹窗支持点击外侧空白关闭，内部点击、拖拽及右键不会误关，保留已有未保存确认。一次性密钥和临时密码仍需显式关闭。
- 修复“系统日志”导航项居中及边框异常，与其他项目统一对齐。

旧 schema 7 的 Linux/systemd 安装升级前必读：

1. 保存完整备份，先安装正式 0.20.3／schema 7 桥接主程序。
2. 使用已验签的 0.20.3 Linux 包，由用户执行其 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3`，核验独立 root 更新器能力支持 schema 7、8 和 7→8。
3. 完成后在网页检查并安装 0.21.2；新程序执行完整性／外键／空间预检、旧格式快照及事务迁移，失败按匹配的旧程序／旧库回退。
4. latest 已前进时，旧网页可能取不到桥接版，按包内 `deploy/schema8-upgrade.md` 提交固定 0.20.3。该指南包含命令、验签及 Windows 步骤。不要用 bootstrap install.sh 覆盖已有安装，不要让旧程序直接读取 schema 8 库。

首次安装直接使用 0.21.2。Windows 原有安装备份并停服后替换已验证程序，保留原数据启动；无 Linux root 工具维护步骤。历史 schema 1–6 或无版本旧测试库仍拒绝自动迁移，不要手改版本标记。

发布本身不操作实际服务器。上述手动维护及实际安装由用户自行执行。
