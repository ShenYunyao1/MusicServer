MusicServer 0.19.0

本版优化容量界面，新增网页上传续传、普通曲库／私人歌单分页和播放器对象级增量同步。

- 容量页按磁盘、分类占用、预留策略、账户额度、安全清理排列。额度改为对齐的只读表格／手机卡片，弹窗调整不限额或 MiB／GiB；已删除账户折叠显示历史占用，用户详情复用同一入口。
- 音频按最多 4 MiB 分块上传并持久保存检查点，可暂停／继续。刷新后恢复队列元数据，重新选择原文件并校验已传部分后续传；不会将整首音频复制到浏览器数据库。未完成任务保留 24 小时，校验预览保留 30 分钟。
- 断连先核对服务端偏移，重复块幂等；写盘同步后才确认。限制账户任务数和收包并发，保留磁盘／额度保护；撤销会话、账户停用／删除／改密后不能推进检查点。备份恢复清除临时检查点。
- 普通曲库、私人歌单及成员每页 50 项，服务端搜索筛选、按需读取歌词详情，减少全量下载和 DOM 节点。页内移动保留页外顺序，版本变化要求刷新。
- 页面可见时每 15 秒轻量检查修订号，只补取当前视图；编辑／拖拽延后，无变化复用节点。刷新失败可重试，旧页面响应不会清空新页面。
- 新播放器 0.4.0 协商对象增量协议，歌单成员／顺序变更无需重置全库快照；按 UUID 每批最多 100 项补取缺少或变化的信息，完整成功后原子保存。授权变化仍清理旧快照；旧版播放器继续使用原协议。
- 发行门禁加入续传和分页浏览器、相关 Linux race，以及旧／新原生 Windows 播放器对候选服务器的实际联调。新播放器另保留固定 0.16.2 基线及最新候选测试。

schema 保持 7，不清空现有数据。已配置 Ubuntu 独立更新器可在网页检查并确认安装；Windows 服务器手动替换。更新服务器与 Windows 播放器使用各自正式版本。更新后刷新网页；浏览器可能要求重新选择本地上传文件和附件。本次不通过 SSH 部署、修改系统服务或重启生产服务器。
