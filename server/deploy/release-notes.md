MusicServer 0.21.0 — 标签与组合筛选

本版正式使用 schema 8，启用公共／个人标签、组合筛选和保存个人条件。schema 7 旧库经过完整性、外键与磁盘预检，保存旧格式快照后事务升级；账户、密码、Key、曲目 UUID、媒体摘要／路径、歌单、邀请／订阅、邮箱与配额保留，不清库、不重新导入音频。

升级前必读（已有 Linux/systemd 安装）：

1. 保存完整备份。主程序必须先安装 0.20.3／schema 7 桥接版。
2. 由用户使用已验签的正式 0.20.3 Linux 包，执行其中的 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3` 维护独立 root 更新器，确认能力文件支持 schema 7、8 及 7→8。
3. 完成上述两步后，在 0.20.3 网页检查并确认安装 0.21.0。新程序执行旧库快照及事务迁移，失败按匹配的旧程序／旧库回退。
4. 0.21.0 成为 latest 后，旧网页可能无法取得 0.20.3；请按包内 `deploy/schema8-upgrade.md` 向现有安装器提交固定桥接版本。完整命令、验签方式、状态核对和 Windows 步骤均在该文档。不要用 bootstrap install.sh 覆盖现有安装，也不要直接换旧程序读取新库。

发布本身不会操作服务器。桥接安装、root 工具维护和实际更新均由用户自行执行。首次安装直接使用 0.21.0；Windows 服务器按备份、关闭、替换已验证程序、保留原数据启动的流程升级，无 Linux root 辅助工具步骤。

新增功能：

- 公共与个人标签分开维护，含风格、演唱语言、版本、情绪、场景和自定义分组。个人整理仅本人可见，不进入公开对象或播放器 Key。
- 管理员维护公共词典和分组，用户维护本人词典；支持搜索分页、别名、重命名、删除保护和同组合并。
- 曲目详情和列表摘要显示标签，右键、键盘菜单及长按可整理；上传支持整批默认和逐首标签草稿，确认入库后应用。
- 已有文件风格按明确的多值结构及词典别名归一，未知值保留；不自动猜测语言、情绪或创建公共词条。重扫保留人工确认／忽略与私人标签，不回写原音频。
- 批量整理区分已选、当前页和全部匹配结果，预览冻结 UUID／版本，确认后执行；大任务提供进度、取消和显式重试。
- 服务端完成公共／个人标签、排除、歌手、专辑、格式、时长、上传者、歌词／封面及未分类的组合筛选、计数、稳定排序和分页，支持保存本人条件和 URL 恢复。
- 页面可见时约每 15 秒检查本人范围修订，变化才重读相关结果；编辑草稿保留，私人变更不刷新其他账户。失效引用明确提示，不静默扩大结果。
- 旧播放器继续使用原曲目、歌单与同步协议，音频缓存身份保持；无需为本次升级重新创建 Key 或重传媒体。

新建数据库默认 schema 8。历史 schema 1–6 或无版本的旧测试库仍拒绝自动迁移；不要手工修改版本标记。升级正常重启后网页需重新登录，原密码和播放器 Key 保留。
