MusicServer 0.21.5 — 用户头像与词条编辑

本版继续使用 schema 8，保留现有账户、密码、播放器 Key、媒体、歌单与标签。已有 0.21.1–0.21.3／schema 8 可在网页检查并确认更新，无需重复维护独立更新器或迁移数据库。更新后重新登录并刷新网页。

新增与优化：

- 个人中心“基本资料”支持选择 JPEG／PNG 头像，原图最多 8 MiB、20MP；支持正方形裁剪、拖动、缩放和方向键调整，先本地预览，保存后应用。
- 保存为经实际解码、重新编码的 256×256 静态 PNG；不接受动画 PNG、SVG 或超限图片。恢复默认也须保存，未保存离开会确认，版本冲突保留草稿。
- 头像同步显示在本人顶部账户入口和个人中心。每账户只保留当前一份，随数据库备份恢复，删除账户同事务清理；不计音频额度，不要求邮箱上传资格，不向匿名或播放器 Key 开放。
- 标签器的现有词条旁新增“编辑”，直接定位分组及最新版本，可修改名称、添加或删除每行一个的别名。保存后标签器重新读取，新增别名立即复用同一标签 ID，不创建重复词条或自动修改曲目绑定。
- 公共词条改名、别名、合并及删除仍限管理员；普通用户可编辑自己的个人词条。词条编辑关闭有未保存确认，叠加编辑对话框不再误关闭底层标签器。
- 修复从桌面切换到手机宽度时，主内容缩进动画短暂挤压顶部账户区造成横向滚动；手机断点立即应用正确布局，保留侧栏开合动画。

旧 schema 7 的 Linux/systemd 安装升级步骤：

1. 保存完整备份，先安装正式 0.20.3／schema 7 桥接主程序。
2. 使用已验签的 0.20.3 Linux 包，由用户执行其 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3`，核验能力支持 schema 7、8 及 7→8。
3. 完成后在网页检查并安装 0.21.5。新程序执行完整性／外键／空间预检、旧格式快照及事务迁移，失败按匹配旧程序／旧库回退。
4. latest 已前进时，按包内 `deploy/schema8-upgrade.md` 向现有安装器提交固定桥接版本；该指南包含验签及完整命令。不要用 bootstrap install.sh 覆盖已有安装，不让旧程序直接读取 schema 8 库。

首次安装直接使用 0.21.5。Windows 原有安装备份并停服后替换已验证程序，保留原数据启动，无 Linux root 工具维护步骤。历史 schema 1–6 或无版本库仍拒绝自动迁移，不要手工修改格式标记。

发布本身不会操作实际服务器；维护和更新由用户自行执行。
