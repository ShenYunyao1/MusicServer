MusicServer 0.21.13 — 歌单顺序播放与紧凑双语歌词

本版沿用 schema 8。当前 schema 8 安装可保留原数据更新，不需要重新导入媒体或重新初始化账户；更新完成后刷新网页。

- 歌单支持顺序播放，从指定曲目向后接续，末首停止；新增“播放全部”、上一首／下一首及播放列表选曲。自有、公开、有效订阅及只读分享歌单统一支持，全局曲库仍为单曲播放。
- 队列读取完整歌单的已保存顺序，不受分页、搜索、勾选或页面切换影响；歌单后续编辑不会打乱当前队列快照。目录变化有界重读，切歌前复核来源权限，跳过已知不可用曲目，网络错误暂停并允许重试。
- 曲名改为左键单击查看详情，移除行空白／歌手／专辑区域点击及全部双击动作；封面播放、复选框热区、路径多选及右键操作保留。
- 歌词与播放列表互斥显示，再次点击入口、点击外部空白或按Esc收起；切歌保持当前面板，关闭面板不影响播放。
- 同步歌词仅显示上一组、当前组、下一组，支持同时间戳原文＋译文，长句自动换行、缩小间距。译文默认开启，可关闭并记住本机偏好；无时间轴歌词提供纯文本阅读入口。
- 发行验收调整为schema 8阶段：上一正式0.21.12到本版的数据保留、实际systemd更新及失败回退、网页和两个固定播放器版本联调。历史schema 7不再作为独立构建或播放器联调矩阵。

安装说明：先备份数据；Windows停服后替换验签通过的固定名称程序，保留原运行数据。已配置更新器的Linux安装可检查并确认更新。首次安装使用本版程序，通过网页设置管理员。播放器客户端本次没有新版本。
