MusicServer 0.18.0

新增完整备份恢复、容量保护与账户额度，将网页和 Windows 播放器联调纳入发行门禁。

- 创建完整或仅数据库备份，支持阶段／字节进度、取消、下载和删除。完整归档包含一致数据库、已入库音频和关联资源、应用设置及逐文件摘要，排除暂存、日志、程序和系统凭证。归档含私人内容，应妥善保管。
- 自动备份默认关闭，网页可设置间隔及保留数量；只自动清理超量的自动归档，手工备份须显式删除。
- `musicserver backup restore --file ... --destination ...` 校验并恢复到新的空目录，保留 UUID、账户和歌单，撤销旧会话、清除暂存、关闭自动备份并重定位媒体根目录。不会覆盖运行库；Nginx、systemd、TLS 配置另行保存。
- 新增“系统设置 → 容量与额度”，显示卷余量、数据库、音频、暂存、备份和更新缓存。默认预留 512 MiB，可调整；上传接收、写入、确认及备份增加低空间拦截，失败清理本次输出。
- 账户音频额度默认不限额，管理员可逐账户设置；按实际存在文件的原始上传者统计，接管不改变占用，重复复用不重复计费，下架仍占空间。降低额度不删除文件，管理员目录扫描不受账户额度限制。
- 安全清理旧更新下载缓存，保留当前、待更新及回退所需版本；不清理已安装程序、回退数据库、媒体或未知文件。
- 登录名保留输入大小写，登录和分享查找仍忽略大小写。管理员可删除已停用且资源已接管的账户，保留原始上传溯源及审计；Key 主动撤销改为直接删除授权和统计，停用账户仍仅暂停 Key。
- 修复接管目标昵称过长时手机账户详情横向溢出，增加长昵称回归及浏览器异步等待验证。
- Linux 网页回归、Windows 原生 WinHTTP／TLS／缓存／真实服务器联调和既有 Go、race、systemd 回退测试共同作为发行门禁。播放器保留固定服务器基线并另测最新候选，不访问生产实例。

schema 保持 7，不清空现有数据。更新后重新登录网页，旧页面可强制刷新。Ubuntu 已配置独立更新器时可在网页检查并确认安装；Windows 服务器仍需手动替换。既有 0.15.1 或更新的独立更新器可继续使用；网页更新不修改 root 更新器、Nginx、systemd 或证书。本次不通过 SSH 部署和重启云端。
