MusicServer 0.21.8 — 页码分页与列表交互优化

本版继续使用 schema 8，保留现有账户、密码、头像、播放器 Key、曲目 UUID、歌单、邮箱、配额及上传续传检查点。已运行 schema 8 的安装可在网页检查并确认更新，不需要重新导入数据库或重复维护更新器；升级后刷新网页。

新增与优化：

- 全局曲库及搜索／筛选结果改为表格顶部、底部同步页码分页：上一页、下一页、相邻页码及省略号、输入页码回车跳转。
- 每页可选20／30／50首，默认50，按账户在当前浏览器记住选择；手机使用两行简化布局。单页和空结果也保留分页设置。
- 页码及每页数量写入地址，支持刷新和前进／后退，兼容旧offset地址；翻页保留搜索、标签筛选与排序，修改每页数量回首页，末页曲目删除后回到最后一个有效页。
- 翻页清空本页勾选，从底部翻页回表头；加载期间上下控件同步禁用，失败可重试本页，新搜索会取消旧曲库读取，迟到响应不覆盖新结果。歌单及授权弹窗的原有分页范围不变。
- 曲库及歌单曲目名称左键双击播放；行内非交互空白单击打开详情，双击切换选择。鼠标单击详情约等待400ms以区分双击，键盘和触屏单击保持直接打开。
- 右键不改变已有选择：未选项的菜单作用于当前项，已选项菜单可作用于已选集合。曲库、歌单、选择弹窗、Key授权及账户资源显示已选／当前页数量。
- 从复选框区域按住鼠标左键，沿途统一选中或取消；快速跨行和重复经过不反复切换。歌单复选框与排序序号分开，保留触屏滚动和原排序手势；切换账户、失焦或取消会终止旧手势。

旧 schema 7 的 Linux/systemd 安装升级步骤：

1. 保存完整备份，先安装正式 0.20.3／schema 7 桥接主程序。
2. 使用已验签的 0.20.3 Linux 包，由用户执行其 `musicserver-updater -config /etc/musicserver/updater.json -refresh-worker 0.20.3`，核验能力支持 schema 7、8 及 7→8。
3. 完成后在网页检查并安装 0.21.8。新程序执行完整性／外键／空间预检、旧格式快照及事务迁移，失败按匹配旧程序／旧库回退。
4. latest 已前进时，按包内 `deploy/schema8-upgrade.md` 提交固定桥接版本；该指南包含验签及完整命令。不要用 bootstrap install.sh 覆盖已有安装，不让旧程序直接读取 schema 8 库。

首次安装直接使用 0.21.8。Windows 原有安装备份并停服后替换已验证程序，保留原数据启动，无 Linux root 工具维护步骤。历史 schema 1–6 或无版本库仍拒绝自动迁移，不要手改格式标记。

发布本身不操作实际服务器，维护及安装由用户自行执行。
