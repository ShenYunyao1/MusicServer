MusicServer 0.20.1

本版增加可选自助注册、邮箱验证和邮件服务，将账户配额集中到用户管理。

0.20.0 候选未通过 Windows 权限测试，未生成正式 Release，原标签保留。原因是运行器将内置管理员 SID 显示为 LA 别名，原测试按文本比较而误判；本版改为比较真实 SID，继续严格检查三项主体、完整访问掩码和继承保护，不修改产品的秘密文件权限。

升级注意：旧账户（包括管理员）默认需要验证邮箱后才能新上传。原有配额、曲目、歌单及只读播放器 Key 保留，不清库；管理员仍可管理服务器、配置邮件，或在用户详情明确设置指定账户免验证。自助注册默认关闭，不能在尚未配置邮件时自行开放。

- 用户管理列表显示用量／额度和邮箱状态；用户详情可调整额度及验证要求。创建成员只填写登录名、明确的配额和验证选项，昵称默认同登录名；临时密码仍只显示一次、首次登录必须修改。
- 系统设置新增“邮件服务”和“注册与账户”。使用通用 SMTP，支持 STARTTLS／隐式 TLS、强制证书校验；保存并测试后可开放注册。注册默认额度只影响之后成功注册的账户，延迟验证或更换邮箱不会重新授额或覆盖管理员调整。
- 个人中心提供邮箱绑定、验证码验证、更换邮箱及本人容量。更换已验证邮箱需当前密码，新邮箱验证成功前保留旧绑定；软删除账户的邮箱占用由管理员显式释放。
- 验证码限时、限制错误次数和发送频率；持久加密发送队列支持重启恢复及有界重试。系统日志可查邮件任务与脱敏失败原因，不记录密码、验证码或完整邮件内容。
- 邮件凭据独立保存在数据库旁受限权限的 .mail-secrets/，不进入普通应用备份。恢复保留账户、绑定和配额，清除待处理验证码／发送任务，关闭注册并要求重新配置、测试邮件服务。
- 上传在读取请求体前、分块检查点及最终写事务内复查会话和验证资格；旧暂存、去重入库、封面和歌词上传不能绕过。现有续传允许查看和取消；普通曲目信息编辑保持原规则。
- 发行门禁增加注册／邮件真实网页流程、假 SMTP／TLS、Windows 秘密文件权限、Linux race 和旧／新原生播放器联调；测试不向真实用户发送邮件。真实 SMTP 需管理员在网页配置，并自行确认收件箱投递。

schema 保持 7，复用扩展元数据，不新增表或列，不删除已有数据。已配置 Ubuntu 独立更新器可在网页检查、确认安装并重启；Windows 服务器手动替换。本次不通过 SSH 部署或重启云端。更新完成后刷新网页，先完成邮件配置或明确账户豁免，再上传；Windows 播放器继续使用正式 0.4.0，无需为本次服务器更新重新安装播放器。
